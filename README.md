# Circular Garden
## Computes the Area, circumference, squareroot, and the rounded up and down of the area
### How to run: Open the file and run it.
### Input Needed: Radius of the Circular Garden 
#### Sample output:
Enter the radius of the garden: 5

Area of the garden : 78.54

Circumference of the garden: 31.42

Square root of the garden : 8.86

Area rounded down : 78.00

Area rounded up : 79.00
